# HYUNDAI MOTORSTUDIO Renewal

현대 모터스튜디오의 공간, 차량, 전시, 프로그램, 예약 흐름을 보여주는 React 데모입니다. 프로젝트 루트의 `PROJECT-GUIDE.md`와 `DESIGN-TOKEN.md`, 제공된 정보구조도·GNB·Figma 메인 화면을 기준으로 구성했습니다.

## 실행

Windows PowerShell 또는 명령 프롬프트에서:

```bash
cd hyundai-motorstudio-renewal
npm install
npm run dev
```

기본 주소는 `http://localhost:5173`입니다. 검증 명령은 `npm run lint`, `npm run build`입니다. 이 작업 환경의 시스템 Node 24에서 Vite 빌드가 비정상 종료되어 프로젝트 개발 의존성에 Node 22를 고정하고 npm 스크립트에서 해당 실행 파일을 사용합니다.

## 구현 범위

- GNB: 현대모터스튜디오 6개 지점, 모빌리티, 전시/프로그램, 예약, 안내
- 메인: 히어로, 소개, 지점 선택, 차량 전환, 전시, 프로그램, 이야기, 안내
- 공개 페이지: 지점, 모빌리티, 전시 상세, 프로그램 상세, 공지사항, 뉴스룸, 멤버십
- 예약: 방문·시승·프로그램 선택, 내 예약 확인과 취소
- 계정: 이메일 데모 로그인, 테스트 로그인, 회원가입 데모, 프로필 수정
- 고객문의: 내 문의 조회·검색·상태 필터·작성·수정·삭제
- 가이드에 보존된 상품 기능: 컬렉션, 상세, 좋아요, 최근 본 상품, 장바구니
- 가이드에 보존된 게시판 기능: 목록, 검색, 카테고리 필터, 작성·수정·삭제, 좋아요

테스트 로그인은 `/login`의 **테스트 계정으로 로그인** 버튼을 누릅니다. 별도 서버나 키가 필요 없습니다. 데모 데이터는 Zustand `persist`를 통해 브라우저 `localStorage`에 저장됩니다. 데이터 초기화는 브라우저의 사이트 데이터 삭제로 수행할 수 있습니다.

## 카카오 연동

프로필의 카카오 주소검색은 버튼을 누를 때 다음 우편번호 스크립트를 불러옵니다. 네트워크가 연결되지 않으면 주소를 직접 입력할 수 있습니다. 카카오 로그인은 인가 요청과 서버 콜백 환경이 없는 데모에서 안내 메시지를 표시합니다. 실제 서비스에서는 서버가 인가 코드 교환과 세션 관리를 담당해야 합니다. 프런트엔드에 REST API 키나 Client Secret을 넣지 않습니다.

`.env.example`에 API 및 카카오 관련 변수 이름을 정리했습니다. 실제 API를 연결하면 `VITE_API_BASE_URL`을 지정하고 `src/common/api`의 데이터 접근 함수를 확장합니다. `VITE_` 변수에는 비밀키를 넣지 않습니다.

## 폴더와 스타일

- `src/assets`: 이미지, 모델, 영상 등 정적 자산
- `src/common`: 데이터, 라우터 경로, API, 유틸리티, 공통 레이아웃
- `src/components`: 페이지 내부의 섹션 및 기능 컴포넌트
- `src/pages`: React Router에 직접 연결되는 화면과 인접 CSS
- `src/store`: 계정, 예약, 문의, 게시판, 좋아요, 최근 본 상품, 장바구니 상태
- `src/styled`: reset, 색상 변수, 폰트, 폼 공통 스타일
- `src/ui`: 서비스 내용에 종속되지 않는 공통 UI
- `src/index.css`: 전역 스타일

이미지는 `/images/...` 경로로 사용합니다. Vite의 정적 자산 기준 폴더는 `src/assets`입니다. 현재 SVG는 자리 표시용으로 제작한 일러스트입니다. 실제 촬영 이미지가 준비되면 같은 경로 또는 데이터의 `image` 필드를 교체할 수 있습니다. 페이지와 컴포넌트 CSS는 해당 JSX 파일 옆에 두고, `src/index.css`는 전역 규칙만 담당합니다.

`src/styled/variables.css`는 `DESIGN-TOKEN.md`의 색상을 반영합니다. Red Hat Display와 Onest는 Google Fonts, SUIT Variable과 Pretendard Variable은 각 공식 프로젝트의 배포 CSS에서 불러옵니다. 폰트 CDN 연결이 없는 환경에서는 시스템 대체 글꼴을 사용합니다.

## 데모 범위와 실제 서비스 전환

이 앱은 프런트엔드 데모입니다. 이메일 가입·로그인은 서버 인증이 아니며, 비밀번호를 저장하거나 검증하지 않습니다. 고객문의 권한은 화면과 Zustand 함수에서 사용자 ID를 확인하지만, 실제 서비스에서는 서버에서 모든 요청의 인증과 소유권을 다시 검사해야 합니다. 예약 가능 시간과 정원도 실제 예약 API와 연결해야 합니다. 프로필 업로드 이미지는 정사각형 WebP로 압축한 뒤 500KB 이하일 때만 브라우저에 저장합니다.

카카오 로그인 서버 연동, 결제, 실제 예약 재고, 관리자 답변 작성은 데모 범위 밖입니다. 접근성·반응형 기본 스타일은 포함했으며, 실제 배포 전에 다양한 기기와 보조 기술에서 별도 검증이 필요합니다.
